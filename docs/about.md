# О компании

## Деятельность и товары

ООО «Инженерные силовые системы и технологии» (сокращённо — **ООО «ИССИТ»**) осуществляет оптовые поставки кормовых концентратов и кормовых добавок для сельскохозяйственных животных.

В каталоге — шесть продуктов:

- **БиоГард** — минеральный корм для нормализации пищеварения у молодняка;
- **ГлюкаСол ПРО** и **ГлюкаСол Баланс** — концентраты для восстановления водно-электролитного баланса;
- **СорбДиар** — концентрат с антидиарейным действием;
- **Лизунец ПроВит** — белково-углеводно-витаминно-минеральный корм для КРС;
- **ПроБуфф** — раскисляющий корм для профилактики ацидоза рубца.

Все продукты предназначены для сельскохозяйственных животных: крупного рогатого скота, свиней, овец, коз и птицы.

Каждая позиция сопровождается полным пакетом технической информации:

- состав корма и показатели качества;
- назначение по видам животных (КРС, птица, свиньи);
- питательная ценность;
- нормы ввода и рекомендации по применению;
- фасовка (пластиковые вёдра по 5/15 кг, мешки по 25 кг, биг-бэги по эксклюзивному заказу);
- срок годности и условия хранения.

## Условия сотрудничества

- **Работаем только с юридическими лицами** — ИП, фермерскими хозяйствами, агрохолдингами.
- **Минимальный объём заказа**: от одной паллеты до фуры (обсуждается индивидуально).
- **Отсрочка платежа** — для постоянных и проверенных клиентов.
- **Логистика**: доставка по Северо-Западу и всей территории России, возможность самовывоза.
- **Документооборот**: официальный договор поставки, ветеринарные свидетельства, декларации соответствия, закрывающие документы.
